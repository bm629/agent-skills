# a3 — declarative-contract enumeration

**Trigger:** always applicable. **Cap:** 14 — **ordering:** whether the artifact is
vendor-published, then schema completeness. **Sources:** `vscode-manifest`, `vscode-contrib`,
`chrome-ext`, `figma-plugins`. **Fallback:** `figma-plugin-typings`.

## Mechanism

Enumerate the **declarative contract** each platform publishes — manifest fields, contribution
points, permission scopes. This is the one angle whose output is a number, which is why its bar is
the strictest here.

## A COUNT IS MEANINGLESS WITHOUT ITS FRAME

One enumerable set yielded **six defensible counts in a single day**: a manifest schema gives 40
naive, 45 under one conditional branch, a different 45 under the other, and 47 as a union that
describes no valid manifest — while the vendor's own page gives 46-under-a-stated-50 by extraction
and 29 by counting sub-page links. None of those is wrong. They answer different questions.

So every enumeration records four things:

| field | why |
| --- | --- |
| `artifact` | which document was counted |
| `method` | how — heading count, table rows, schema keys, link enumeration |
| `branch` | which conditional branch, where the artifact has one |
| `reconciled_by` | a SECOND independent derivation |

## The second derivation is not belt-and-braces

An extraction of a machine-readable catalog once returned a well-formed, plausible row — name,
description, URL, fileMatch — that **did not exist**. Mechanical re-parsing of the same file found
1,448 entries, zero matching on any field, and the reported URL 404ing. The only thing that caught
it was re-deriving the count a different way.

The positive control: one platform's contribution points come to 38 by three independent
derivations on two dates. Agreement across methods is what makes a count credible.

## Prefer the vendor's artifact, and know when it is not theirs

A community-maintained schema is not the vendor's. One in this corpus still enumerates a manifest
version the vendor page says is no longer supported, and retains keys the platform removed. Where
the machine-readable artifact and the normative text disagree, **the normative text governs and the
disagreement IS the finding.**

## Unique coverage

The only angle producing a countable contract surface — the input every downstream sizing decision
rests on.
