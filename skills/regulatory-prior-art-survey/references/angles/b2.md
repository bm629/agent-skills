# Angle b2 — accessibility-law and conformance-standard retrieval

- **Conditional:** `ui.has_ui = true`. **Anchor:** `ui.has_ui`.
- **Searches these axes:** `instrument`, `control-catalog`, `jurisdiction`, `ui-term`.
- **Sources:** `eu-cellar`, `section508-gov`, `access-board`, `w3c`. **Fallback:** `w3c`.
- **Cap:** 15 — **ordering:** conformance level, then criterion number.

## Not tautological — and this is where reading the table against the WRONG type goes wrong

`ui.has_ui` is the type trigger of a DIFFERENT survey, and a sibling shipped a defect by anchoring
on its own trigger. Inside THIS survey the trigger is `regulatory.applies`, which says nothing
about a UI, so the predicate genuinely gates. The same predicate is a defect in one type and
correct in another — which is why the check is per-type and not a lookup.

## Mechanism

**Start from the LAW** — what level does it mandate, for whom, from when — then resolve the
referenced standard and traverse its success-criterion list at that level.

**Never start from the standard.** WCAG alone says nothing about whether it binds this product, and
a survey that starts there produces a conformance checklist with no obligation behind it.

## The level default

An undeclared `ui.accessibility.required_level` defaults to **AA**, which is what the design-system
authoring skill requires unconditionally. A declared level overrides it. `required_level` is an
optional property of an optional object — a widener, never an anchor.

## Why this cap

The accessibility-LAW set is small and named — the European Accessibility Act, Section 508, and
national transpositions. The standard it references is large, but the standard is `a3`'s unit and is
counted there as one catalog. Counting criteria here would size this cap against the wrong thing.

## What only this angle covers

The only angle where a design-system constraint arrives as a **legal obligation with a deadline**.
Distinct from the visual and user-research surveys' accessibility angles, which retrieve convention
and research rather than law.
