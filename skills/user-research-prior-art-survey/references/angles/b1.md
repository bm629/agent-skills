# b1 — regulated-domain research retrieval

**Trigger:** conditional — `regulatory.applies = true`. **Anchor:** `regulatory.applies`
(required). **Cap:** 30. **Source:** `europepmc-api`. **Fallback:** `crossref`.

## Mechanism

Query the biomedical and regulated-domain literature for human-factors and usability work on the
scope's task and population, **through the REST API host**. The web front end of this corpus is
a separate registry entry and is excluded: its robots file names several crawlers individually
and closes with a catch-all `Disallow: /`, so this survey is not among the permitted ones. The
API host is a different host with a different policy and a declared 10-second crawl delay.

That split is the whole point of the entry. A run that reaches the website because it recognised
the corpus name has breached a policy the registry already recorded.

## Query strategy

Query by `user-population` and `task`, crossed with `method` where the population is clinical.
Regulated-domain human-factors work is indexed under terms this survey's other angles never use
— "use error", "human factors validation", "summative usability" — so the map's method group
will usually under-serve this angle. That is expected: record the queries as run and let the
coverage show it, rather than inventing terms the map does not carry.

Honour the 10-second spacing and record the `selection` on every reached cell.

## Unique coverage

Human-factors research conducted under a regulatory obligation, which is where study populations
are clinical rather than convenience samples. A finding about older adults from a recruited
university pool and one from a clinical cohort are different evidence, and only this angle
reaches the second.

## Failure modes

- **Reaching the website instead of the API.** The commonest way to breach this source's terms,
  and it looks like ordinary retrieval in the output. The cell must name `europepmc-api`.
- **Firing the angle on an unregulated scope.** The trigger rests on a required field, so a scope
  that declares `regulatory.applies = false` yields `holds: false` and this angle does not run.
  Running it anyway spends the cap on literature the scope ruled out.
- **Treating a clinical-trial abstract as a finding.** Same admission rule as everywhere: full
  text retrievable without bypassing a paywall, AND a stated method. Much of this corpus is open
  access, but not all of it.
- **Confusing regulatory guidance with research.** A regulator's human-factors guidance document
  prescribes; it does not report a study. It is admissible only where it states the evidence
  behind the prescription.

## Fallback

`crossref` — independent of the biomedical index entirely, and already an active source for a1,
so the fallback cannot fail for the same reason the primary did. Regulated-domain work carries
DOIs like anything else.

## Cap

30, sized against the 10-second crawl delay: about five minutes of retrieval. The regulated slice
of any one scope is narrow, and a larger cap would pull in clinical literature with no interface
in it.
