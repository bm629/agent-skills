# Research provenance — reviewing-code-prior-art-survey

This skill runs no research pass of its own by design: it is the reviewing
half of a pair, and its bar is single-sourced from the pair's SHARED research
dossier (maintained with the producer skill's design records). The dossier
consolidates two citation-tracked, sanitized deep-research rounds:

- Search-protocol + record standards: PRISMA-S (per-source reporting:
  exact query as run, date, counts, justified limits), PRESS 2015 (peer
  review of search strategies — the direct ancestor of this skill's craft
  conditions), SKOS (vocabulary relations behind expansion-quality
  judgment), query-expansion literature (negative terms/disambiguation),
  living systematic reviews (the baseline + inheriting-delta model behind
  the delta lens), data-provenance practice (revision discipline), CodeMeta
  / schema.org (candidate record completeness), Software Heritage / SWHID
  (canonical identity), MSR-2020 GitHub deduplication (copy honesty),
  screening-tool practice (per-source records, point-in-time signals).
- Discovery-channel taxonomy: the 6+3 angle set and the per-angle source
  registry the coverage conditions lean on.

The eighteen conditions in `references/conditions.md` restate the dossier's
quality bar verbatim-ish (same numbering, same headlines) — the producer
produces to that bar, this skill asserts it. Any change to the bar changes
the shared dossier first, then both skills.

The review-method shape (Orient / Judge / Decide+emit, exactly-one-VERDICT,
no-false-revise, cannot-grade-own-homework) follows the established
producer/reviewer pair pattern this collection uses for discovery and the
document library.
