# `a1`

First-party engineering-narrative retrieval. Walks the discovery and curated indexes for published scaling narratives, and records one coverage cell per (group, source).

## Wave-0 input

`system-class`, `load-dimension`, `named-technology`

Its input comes from **wave 0 and its own channel only**. An angle taking its input from a sibling
angle's OUTPUT would be reading a vocabulary the sibling minted, which L-9 forbids — and
`seed_input` is the anti-drift mechanism that makes the rule checkable.

## Applicable group types

`system-class`, `load-dimension`, `named-technology`

The owed grid crosses these groups with this angle's own sources INTERSECTED with the map's ACTIVE
set. All three terms: dropping any one is wrong in a measurable way.

## Sources

- `hn-algolia`
- `awesome-scalability-index`
- `engineering-blogs-index`
- `highscalability-archive`
- `github-blog`
- `infoq`
- `open-engineering-blogs`

`fallback`: `awesome-scalability-index` — When discovery is unreachable the curated index still yields case studies by category, which is the same corpus reached a different way.

## When it runs

Always. `trigger: always`, no `predicate`, and `trigger_anchor: []` — this type follows the five shipped validators that guard on truthiness and accept an empty anchor on an always-on angle.

## Cap and ordering

**`cap: 40`.** A BUDGET, not a measurement. The long tail is unbounded — hn-algolia is a live full-text index and open-engineering-blogs is per-host — so no count clears it; 40 is what one child can read at depth. `hit: true` is this angle's normal path.

**`ordering_signal`:** Recency of the narrative (published date descending), then the source's own listing order. Both signals exist for every source this angle walks: each index carries a date and every listing has an order.

Record `bound{cap, hit, ordering, dropped_note, ordering_deviation}`. The cap is transcribed
VERBATIM from the registry — an author does not widen their own cap. `hit: true` owes a
`dropped_note` a reader could RE-APPLY: name the ordering position reached and the first row that
fell off, never "the rest were dropped".
