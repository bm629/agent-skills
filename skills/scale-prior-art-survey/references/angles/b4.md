# `b4`

Capacity-envelope retrieval. Walks the published provider and component limits for the hard numbers a design has to live inside.

## Wave-0 input

`named-technology`, `system-class`

Its input comes from **wave 0 and its own channel only**. An angle taking its input from a sibling
angle's OUTPUT would be reading a vocabulary the sibling minted, which L-9 forbids — and
`seed_input` is the anti-drift mechanism that makes the rule checkable.

## Applicable group types

`named-technology`, `system-class`

The owed grid crosses these groups with this angle's own sources INTERSECTED with the map's ACTIVE
set. All three terms: dropping any one is wrong in a measurable way.

## Sources

- `docs-aws-quotas`
- `azure-limits`
- `gcp-quotas`
- `kubernetes-docs`
- `component-docs`

`fallback`: `component-docs` — When a provider's limits page is unreachable the component's own documentation still publishes its ceilings.

## When it runs

`precondition`: archetype.primary not in {cli-tool, library-sdk, desktop-app, browser-extension} OR integrations.expected OR archetype.secondary INTERSECTS {api-service, web-app, ml-service, infra-platform, data-pipeline}

**`trigger_anchor`**: `archetype.primary`, `integrations.expected` — each a REQUIRED capability-map leaf, so the predicate cannot fail closed on a map that omits an optional field.

**`widening_legs`**: `archetype.secondary` — OPTIONAL fields only.

**`predicate_omits`**: 
- business.platform — being a platform implies tenancy questions, which are b7's, not capacity ceilings.

## Cap and ordering

**`cap: 25`.** A BUDGET. component-docs is per-vendor, so the union depends on which components the scope names and cannot be counted in advance.

**`ordering_signal`:** The source's own listing order, then the declaration order in `sources` above. Limits pages publish no dates and no ranking, so listing order is the only signal total across all five.

Record `bound{cap, hit, ordering, dropped_note, ordering_deviation}`. The cap is transcribed
VERBATIM from the registry — an author does not widen their own cap. `hit: true` owes a
`dropped_note` a reader could RE-APPLY: name the ordering position reached and the first row that
fell off, never "the rest were dropped".
