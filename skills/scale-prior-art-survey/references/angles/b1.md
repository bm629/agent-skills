# `b1`

Tail-latency and real-time evidence retrieval. Walks the literature and component documentation for measured latency distributions and the configurations that produced them.

## Wave-0 input

`named-technology`, `load-dimension`

Its input comes from **wave 0 and its own channel only**. An angle taking its input from a sibling
angle's OUTPUT would be reading a vocabulary the sibling minted, which L-9 forbids — and
`seed_input` is the anti-drift mechanism that makes the rule checkable.

## Applicable group types

`named-technology`, `load-dimension`

The owed grid crosses these groups with this angle's own sources INTERSECTED with the map's ACTIVE
set. All three terms: dropping any one is wrong in a measurable way.

## Sources

- `usenix`
- `arxiv-listing`
- `component-docs`
- `techempower`
- `hn-algolia`

`fallback`: `usenix` — Peer-reviewed proceedings carry the measured distributions when a vendor's own documentation states only a target.

## When it runs

`precondition`: scale.real_time in {soft, near, hard} OR scale.latency_sensitive

**`trigger_anchor`**: `scale.real_time` — each a REQUIRED capability-map leaf, so the predicate cannot fail closed on a map that omits an optional field.

**`widening_legs`**: `scale.latency_sensitive` — OPTIONAL fields only.

**`predicate_omits`**: 
- scale.throughput — a throughput requirement does not by itself imply a tail-latency obligation, and b5 owns that ground.

## Cap and ordering

**`cap: 30`.** A BUDGET. component-docs is per-vendor and hn-algolia is unbounded, so no union exists to count.

**`ordering_signal`:** Measured-percentile depth first (a source reporting p99 or beyond outranks one reporting a mean), then publication date descending. Both are readable on every source this angle walks.

Record `bound{cap, hit, ordering, dropped_note, ordering_deviation}`. The cap is transcribed
VERBATIM from the registry — an author does not widen their own cap. `hit: true` owes a
`dropped_note` a reader could RE-APPLY: name the ordering position reached and the first row that
fell off, never "the rest were dropped".
