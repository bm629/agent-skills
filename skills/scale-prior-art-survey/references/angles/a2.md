# `a2`

Peer-reviewed systems-literature retrieval. Walks the proceedings and preprint listings and the DOI layer for measured systems results.

## Wave-0 input

`system-class`, `load-dimension`

Its input comes from **wave 0 and its own channel only**. An angle taking its input from a sibling
angle's OUTPUT would be reading a vocabulary the sibling minted, which L-9 forbids — and
`seed_input` is the anti-drift mechanism that makes the rule checkable.

## Applicable group types

`system-class`, `load-dimension`

The owed grid crosses these groups with this angle's own sources INTERSECTED with the map's ACTIVE
set. All three terms: dropping any one is wrong in a measurable way.

## Sources

- `usenix`
- `pvldb`
- `arxiv-listing`
- `crossref`
- `semantic-scholar`

`fallback`: `crossref` — When a proceedings listing cannot be walked, the DOI layer still resolves the same papers.

## When it runs

Always. `trigger: always`, no `predicate`, and `trigger_anchor: []` — this type follows the five shipped validators that guard on truthiness and accept an empty anchor on an always-on angle.

## Cap and ordering

**`cap: 45`.** A BUDGET. Two of the five sources are unbounded APIs and arxiv-listing is a recency window, so the union cannot be counted; 45 is sized to one child's reading depth over five channels.

**`ordering_signal`:** Citation count descending where the source exposes one, then publication date descending. Crossref and semantic-scholar both expose citations; usenix, pvldb and arxiv expose dates, so the tie-break is total over every source this angle walks.

Record `bound{cap, hit, ordering, dropped_note, ordering_deviation}`. The cap is transcribed
VERBATIM from the registry — an author does not widen their own cap. `hit: true` owes a
`dropped_note` a reader could RE-APPLY: name the ordering position reached and the first row that
fell off, never "the rest were dropped".
