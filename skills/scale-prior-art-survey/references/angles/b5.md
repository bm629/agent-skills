# `b5`

Independent benchmark retrieval. Walks the audited and continuously-run public benchmarks for throughput evidence with its configuration disclosed.

## Wave-0 input

`named-technology`, `load-dimension`

Its input comes from **wave 0 and its own channel only**. An angle taking its input from a sibling
angle's OUTPUT would be reading a vocabulary the sibling minted, which L-9 forbids — and
`seed_input` is the anti-drift mechanism that makes the rule checkable.

## Applicable group types

`named-technology`, `load-dimension`

The owed grid crosses these groups with this angle's own sources INTERSECTED with the map's ACTIVE
set. All three terms: dropping any one is wrong in a measurable way.

## Sources

- `tpc-results`
- `spec-results`
- `techempower`
- `clickbench`
- `crossref`

`fallback`: `techempower` — A continuously-run public benchmark covers the same ground when an audited result does not exist for the component.

## When it runs

`precondition`: scale.data_volume in {large, extreme} OR scale.concurrency in {high, extreme} OR scale.throughput in {high, extreme}

**`trigger_anchor`**: `scale.data_volume`, `scale.concurrency` — each a REQUIRED capability-map leaf, so the predicate cannot fail closed on a map that omits an optional field.

**`widening_legs`**: `scale.throughput` — OPTIONAL fields only.

**`predicate_omits`**: 
- scale.real_time — b1 owns latency; a throughput benchmark is not a tail-latency measurement.

## Cap and ordering

**`cap: 20`.** A BUDGET. crossref is unbounded and the benchmark rounds are re-run continuously, so a union counted today expires.

**`ordering_signal`:** Configuration completeness first (a result disclosing hardware and tuning outranks a bare number — the full-disclosure discipline `configuration_stated` records), then result date descending. Both readable on all five.

Record `bound{cap, hit, ordering, dropped_note, ordering_deviation}`. The cap is transcribed
VERBATIM from the registry — an author does not widen their own cap. `hit: true` owes a
`dropped_note` a reader could RE-APPLY: name the ordering position reached and the first row that
fell off, never "the rest were dropped".
