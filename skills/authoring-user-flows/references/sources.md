# Sources — authoring-user-flows

Research provenance for this skill. The skill synthesizes the shared user-flows
dossier (`docs/superpowers/agent-flow/authoring-user-flows/research/user-flows-dossier.md`),
which was produced via the `deep-research` capability with >=2 reputable sources per
structural claim. Sources consumed for facts only; nothing lifted as instructions.

## Section set + notation (what a user-flows doc contains)

- Justinmind — Ultimate Guide to User Flows (entry points; happy + unhappy paths)
- altexsoft — How to Design and Document User Flows (process; flowchart notation;
  persona/goal tie-back)
- Adobe — User flow diagrams: how to create them (notation; screens; success states)
- mockflow — User Flow Best Practices (happy-path-first; decision points; error paths)
- Zeplin Gazette — What are user flows (screens/states traversed)
- Infinum — UX Flowcharts (standard shapes)
- Nielsen Norman Group — Wireflows; User Journeys vs. User Flows (definitions; the
  flow-vs-journey-vs-wireflow boundary)
- UX Planet — UX Glossary: Task Flows, User Flows, Flowcharts (terminology distinctions)

## Derivation method (deriving flows from goals/personas, not inventing them)

- Nielsen Norman Group — Personas vs. Jobs-to-Be-Done (goals as jobs; map jobs to
  personas)
- SIVO Insights — Designing User Flows Using Jobs To Be Done (job-first flow design)
- User Interviews — Jobs to Be Done (JTBD) in UX Research (research methods underneath)
- Ramotion — Happy Path in UX Design (map the happy path first)
- Overflow — Storytelling in the design process (the flow-as-narrative framing)
- flowmapp — User flow diagrams in practice (labels/annotations for readability)

## Quality bar (edge cases, error states, no dead ends, completeness)

- Nielsen Norman Group — The Edge Cases that Break Hearts (And Products) (edge-case
  categories; full UI state stack; no dead ends)
- balsamiq — How to find edge cases before they become expensive issues (systematic
  edge-case enumeration; capture every assumption)
- wavespace — 8 Common Mistakes in UX User Flows to Avoid (missing branches; incomplete
  error handling; dead ends; empty states)
- goodcode — Dead-end UX: Navigating unexpected endings (recovery paths, not dead ends)
- uxknowledgebase — Edge cases in UX design (boundary analysis; error/empty/loading)
