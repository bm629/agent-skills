# Angle a4 — literature and preprint recency walk

- **Conditional:** none — always-on angle.
- **Searches these axes:** `ml-task`, `domain-term`, `method`.
- **Sources:** `arxiv-listing`, `crossref`, `semantic-scholar`, `openalex`, `hf-papers`. **Fallback:** `crossref`.
- **Cap:** 30 — **ordering:** recency, then whether the paper's artifact has a resolvable locator.

## Mechanism

Subject-listing traversal, never a site search — the arXiv listing host permits /list and /abs and forbids /search, and the API host forbids everything. A paper is NEVER a record: it is provenance on the artifact it introduced, and an artifact with no locator is not admitted.

## Why this cap

A recency walk, not a systematic review; past 30 the marginal preprint stops moving a rung decision.

## Why this fallback

DOI resolution with no key and a polite pool; the one channel that answers when the others throttle.

## What only this angle covers

The only angle that reaches work not yet in any registry. A model published last week has no
downloads, no leaderboard row and often no card — and the preprint that introduced it is the only
evidence that exists.

**Traverse the listing; never search.** The arXiv listing host permits `/list`, `/abs` and `/pdf`
and forbids `/search`; the API host forbids everything. This is a RECENCY WALK by subject, and
treating it as a search endpoint is both a terms violation and a retrieval that returns nothing.

**A paper is never a record.** It cannot be adopted. Its identifier belongs in the artifact's
`provenance.arxiv_id`, on the model or dataset it introduced. A paper whose artifact has no
resolvable locator produces no candidate at all — which is a finding about the work's maturity, and
exactly what a build-vs-buy decision needs to know.
