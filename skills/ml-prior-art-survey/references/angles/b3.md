# Angle b3 — serving-performance evidence retrieval (conditional)

- **Trigger:** conditional — `scale.real_time in {near, hard} OR scale.concurrency in {high, extreme} OR scale.availability_target in {"99.99", "99.999"}`
- **Anchor (required-rooted):** `scale.real_time`, `scale.concurrency`, `scale.availability_target`.
- **Searches these axes:** `ml-task`, `runtime-format`.
- **Sources:** `artificial-analysis`, `mlcommons`, `ngc-catalog`. **Fallback:** `artificial-analysis`.
- **Cap:** 20 — **ordering:** whether the measurement is independent, then whether the hardware is stated.

## Mechanism

Retrieve measured inference latency and throughput. A number without its hardware and batch configuration is not a measurement — it is a claim whose frame is missing, and this angle records the frame or records nothing.

## Why this cap

Measured serving numbers come from few publishers.

## Why this fallback

The only source measuring across vendors on a stated, repeated methodology.

## Why this predicate is not a tautology

All three legs are required leaves and all three are cross-cluster — nothing in `data_ml` is restated, so the angle cannot be entailed by the type trigger.

The type-level trigger is `data_ml.ml_involvement != 'none'`. This angle names a
PROPER SUBSET of what that admits, so a project can satisfy the type and leave this
angle false — which is the discrimination the gate exists to make. An angle whose
predicate merely restated the type trigger would fire on every survey and the
conditional marking would be decorative.

## What only this angle covers

The only angle that measures the model in the shape it will actually be served. A benchmark score
says what a model can do; this says whether it can do it inside the request budget.

**A latency number without its hardware and batch configuration is not a measurement.** It is a
claim whose frame is missing, and this corpus publishes plenty of them. Record the frame or record
nothing — a p50 with no batch size cannot be compared to another p50 with no batch size.

robots file names.
