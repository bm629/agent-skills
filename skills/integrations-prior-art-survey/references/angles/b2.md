# `b2` — event/webhook delivery conventions

## Mechanism

Walk the map's `service` AND `pattern` groups — both — plus the three published event
conventions' adopter lists. Never reads another angle's candidates.

**This angle takes its input from WAVE 0 or the capability map, never from another search child.**
It discovers from the vocabulary map's own groups and enriches from its own channel. The
cross-angle join happens at two places that are not angles — the coordinator's in-memory merge and
the extract child's deep read, both wave 2.

## Axes it searches

- **`service`** — third-party services already named in the scope
- **`pattern`** — the integration patterns expected

adoption across the three was never counted, and a terminal is the last channel rather than the
best one.

## Cap and ordering

**Cap: `60`.** BUDGET. The coordinator's `communication` figure of 67 (2026-08-22, not re-measured this pass)
sized it, and that is a Nango CATEGORY count rather than b2's own corpus — b2 walks the event
conventions' adopter lists and the map's `service` group, whose union nobody counted.

**Ordering: event-surface richness (published event-type count), then service name.** Transcribe it VERBATIM into `bound.ordering`. Where the run
could not apply it, record the ordering it DID apply and say why in `ordering_deviation` — an
ordering nobody can re-apply is a cap with no honesty behind it.

## Precondition, in BOTH directions

**It holds when:** `scale.real_time in {near, hard} OR archetype.primary in {api-service, data-pipeline, infra-platform, agent-automation} OR integrations.complexity = complex`.

**It does NOT hold when** none of those disjuncts is satisfied; the map records `holds: false` naming the DECIDING value, and this angle is not dispatched.

## What this angle uniquely covers

the delivery semantics a service publishes — event types, retry, signing — which a catalog row
never carries.

**A qualitative WIDENER, recorded in `predicate_omits`.** Whether the product ITSELF emits webhooks (`security.external_attack_surface.has_webhooks`) is property-less in the schema, so it cannot gate anything. It widens this angle's precondition in prose and never anchors it — a widener is not a fold.

## No sibling dependency

This angle names no other angle's output anywhere above. Its mechanism reads the vocabulary map and
its own sources, so a survey missing any other angle still dispatches this one. Where a naive
reading of the taxonomy would have it consume `a1`'s candidates, the resolution is that it
DISCOVERS from wave 0 and ENRICHES from its own channel.

## Absent input

If every source above is unreachable, record each cell with its status and observable cause, set
`outcome: vacated` with the cause, and record NO candidates — recording one would mean a search
happened. If the angle was ruled out by the map, `outcome: not_run` with the map's verdict, and
nothing else.
