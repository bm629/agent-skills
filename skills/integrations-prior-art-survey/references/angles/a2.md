# `a2` — API-descriptor retrieval

## Mechanism

Resolve the map's `service` names to a machine-readable descriptor AND walk the descriptor index
by the map's `category` terms — surfacing raw APIs with no automation connector, which a1
structurally cannot see. Discovers and enriches from its own channel.

**This angle takes its input from WAVE 0 or the capability map, never from another search child.**
It discovers from the vocabulary map's own groups and enriches from its own channel. The
cross-angle join happens at two places that are not angles — the coordinator's in-memory merge and
the extract child's deep read, both wave 2.

## Axes it searches

- **`service`** — third-party services already named in the scope
- **`category`** — the integration categories the product's capabilities imply

## Precondition, in BOTH directions

**It holds when:** `always`.

**It cannot fail to hold.** This angle is ALWAYS-ON: there is no predicate to satisfy and no classification value that rules it out. A map recording `holds: false` for it is refused by `always-on-angle-holds`.

## What this angle uniquely covers

raw APIs with a machine-readable descriptor and NO automation connector — which a1 structurally
cannot see, because it walks connector catalogs.

**Required sub-topic — integration PATTERNS.** The descriptor KIND is the evidence, plus AsyncAPI's `servers[].protocol` where the descriptor is AsyncAPI — OpenAPI's Server Object has NO `protocol`, so for an OpenAPI descriptor (which apis-guru, this angle's terminal, overwhelmingly carries) the kind plus the operation shape is what there is. It is what supplies the `integration_pattern` a downstream consumer reads. Folded here for the same reason: `integrations.patterns` is property-less.

## No sibling dependency

This angle names no other angle's output anywhere above. Its mechanism reads the vocabulary map and
its own sources, so a survey missing any other angle still dispatches this one. Where a naive
reading of the taxonomy would have it consume `a1`'s candidates, the resolution is that it
DISCOVERS from wave 0 and ENRICHES from its own channel.
